# Skill-Tracker-Web-Application
Skill Tracker

A web-based application that enables organizations to track, manage, and analyze employee skills. Managers can assign skill ratings, identify skill gaps, and plan training needs across teams.
This project was developed by a team of three during an internship, using C#/.NET for the backend and HTML, CSS, JavaScript for the frontend.

🚀 Features

**Employee Skill Management**
Add employees and assign skill ratings across different categories.

**Skill Gap Identification**
Automatically highlights low-rated skills to help plan training needs.

**Role-Based Access**
Manager vs Employee views.

**Interactive UI**
Clean web interface built using HTML, CSS, and JavaScript.

**Backend APIs using .NET**
Secure and scalable API endpoints for managing skill data.

**Dashboard & Reports**
View team-wise skill proficiency, export reports.
